# P-Broll creation handoff

版本：0.2.0
日期：2026-08-06

## 研究来源与候选特定经验

- `gbro-collage-broll`：三闸门审批能把隐喻、静帧和视频费用分开控制；保留并扩展。
- `vox-director`：主题预设适合把风格字段锁定为文字规则；保留中文显示名与稳定英文 ID。
- 用户低多边形参考视频：说明视觉风格和生成协议必须分离；新增 `low-poly-animation` 与 `single-first`。

## 原创贡献

- 将纸拼贴和低多边形动画统一到同一成本门禁下，但为两者设置不同图像输入、提示词和 QA。
- 图片修改统一禁止旧图参考，低多边形模式额外检查拓扑、人物身份和几何稳定。
- 手动生成包、QA 对照图和批量总览根据 `frame_mode` 自动分流。

## 证据标签

- **design advantage**：模式化帧输入能避免单首帧低多边形任务被首尾帧准入规则误拒。
- **validated advantage**：本地单首帧打包、首帧相似度 QA、单条总览和原拼贴兼容脚本已通过测试。
- **hypothesis**：低多边形模式在真实平台上的模型质量、费用和跨镜头身份稳定性，尚无 provider-backed 或 human-blind-review 证据。

## 发布边界

当前工作树适合继续本地开发和审查；在真实低多边形平台试跑、干净安装、人工评审和 PR 发布前，不宣称“生产级”或“全平台已验证”。
