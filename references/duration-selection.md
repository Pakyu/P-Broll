# 视频时长动态判定

Gate 1 为每个 B-roll 或 beat 确定目标时长时读取本文件。目标范围为 4–15 秒。

## 1. 优先级

1. 用户明确指定 4–15 秒时，优先使用用户时长，但仍计算动作所需时间做安全检查。
2. 用户未指定时，根据内容复杂度计算。
3. 用户要求小于 4 秒时，说明组装或主体动作可能不可读，建议 4 秒或简化为一个动作。
4. 用户要求超过 15 秒时，优先拆成两个 beat，不把单镜头强行拉长。

## 2. 动作单元

先把视觉过程拆成动作单元。拼贴模式可按“滑入 → 展开 → 连线”拆分；
低多边形动画可按“人物转身 → 指向屏幕 → 镜头推进”拆分。

每个动作单元分配：

| 动作类型 | 时间 |
|---|---:|
| 简单滑入、落下、卡位 | 0.9 秒 |
| 两组协调、对齐、连接、比较 | 1.3 秒 |
| 展开、翻转、替换、因果转化 | 1.8 秒 |

固定时间按 `frame_mode` 区分：

- `first-last` 拼贴：空首帧 0.5 秒，复杂场景 0.8 秒；完成态停留至少
  1.2 秒，信息复杂时 1.8–2.0 秒。
- `single-first` 低多边形：起始画面停留 0.3 秒，复杂场景 0.6 秒；
  动作结束后稳定 0.8 秒，复杂时 1.2 秒，手动覆盖范围 0.8–1.5 秒。
- 关系理解：无新增 0 秒；简单关系 0.8 秒；复杂因果/对照 1.5 秒。

计算：

```text
raw_duration = 起始停留 + 所有动作单元时间 + 关系理解 + 结尾稳定时间
target_duration = ceil(raw_duration)，并限制在 4–15 秒
```

实际执行优先调用：

```bash
python <本skill目录>/scripts/select_duration.py \
  --frame-mode <first-last|single-first> \
  --simple <数量> --coordinated <数量> --transform <数量> \
  --relation <none|simple|complex> \
  [--complex-scene] [--platform-durations 5,10,15]
```

用户指定时长时使用 `--user-duration <4-15>`。脚本不擅自改长用户时长；若动作估算超过该时长，会返回 `user_duration_insufficient=true` 与 `needs_split=true`，此时必须简化动作或拆 beat 后再继续。

十套拼贴主题使用 `first-last`；低多边形动画 `low-poly-animation` 必须使用
`single-first`。

## 3. 快速校准表

| 内容复杂度 | 常见情况 | 建议时长 |
|---|---|---:|
| 极简 | 1–2 组物件、1 个动作、无关系变化 | 4 秒 |
| 简单 | 2–3 组物件、2 个简单动作 | 5–6 秒 |
| 中等 | 3–4 组物件、3 个动作、连接或对照 | 7–9 秒 |
| 复杂 | 4 组物件、多阶段展开、因果或转化 | 10–12 秒 |
| 高复杂 | 4 组物件但包含 5 个以上动作单元，需要观察完成态 | 13–15 秒 |

若计算达到 15 秒仍显拥挤，返回 Gate 1 拆 beat 或删动作，不继续增加时长。

## 4. 平台时长档位

平台只提供离散时长时，选择**不短于 target_duration 的最小可用档位**。例如目标 7 秒、平台只有 5/10 秒，提交 10 秒。

必须记录：

- `duration_target`：内容计算得到的目标时长。
- `duration_submitted`：实际向平台提交的时长。
- `duration_reason`：物件组数、动作单元和关系复杂度的简短说明。

平台最大时长低于目标时，不要静默压缩。先减少动作、拆 beat 或转用支持更长时长的平台。

## 5. 完整讲解片

先在 `beats.json` 根级写入 `target_duration`（通常 45–60 秒），再逐 beat 独立计算 4–15 秒，不统一写死。通常使用 8–10 个 beat，但全片预算优先：复杂内容可拆 beat，简单内容应合并 beat，所有 beat 预计时长之和应尽量落在目标 ±3 秒内。旁白仍是最终拼装主时钟：

- 旁白比视频长时，用尾帧定格补齐。
- 不要仅为匹配旁白长度给没有动作的画面购买更长生成时长。
- 视频动作比旁白复杂时，优先简化动作或调整 beat 文本，不让核心动作被截断。
- 拼装脚本发现预计总长与 `target_duration` 相差超过 3 秒时会警告；先调整节奏，不直接发布超长或过短成片。
