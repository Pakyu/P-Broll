# 视频生成路由

## 目录

1. 硬性准入条件
2. 一级：Agent 自带或集成能力
3. 二级：用户指定平台 CLI
4. 三级：小云雀 CLI
5. 四级：手动生成包
6. 五级：HyperFrames 最终兜底
7. 统一回收与 QA

## 1. 硬性准入条件

Gate 3 的首要条件不是工具可用，而是用户已经看过当前静帧并明确批准该版本进入视频生成。开始前检查 `gate2-qa.md` 中的批准记录；完整讲解片还要检查对应 beat 的 `gate2_approved=true` 与 `gate2_approved_file`。开始前的“直接跑完”、概括授权、沉默或 Agent 自行判断均不能替代图片生成后的确认。

自动视频生成工具必须满足：

- 显式接收首帧与尾帧，或等价的 first frame / end frame / tail frame 参数。
- 支持 9:16 竖版或根据输入图自动继承比例。
- 支持 4–15 秒中的 `duration_target`，或提供不短于目标的离散时长档位。
- 音频不是普通 B-roll 的准入条件；模型生成什么音轨就按原样保留。只有完整讲解片才额外抽离音频。
- 能返回本地文件或可下载 URL。

只支持单张参考图的 image-to-video 不能保证完成态，不进入自动路线。

## 2. 一级：Agent 自带或集成能力

先检查当前 Agent 暴露的工具、插件、MCP 或原生视频能力。若存在满足硬性条件的工具，直接优先使用：

1. 查看工具声明，确认首尾帧参数和合法取值。
2. 读取 `duration_target`，匹配平台时长档位；有模型选择时展示可用模型、首尾帧能力和预计费用，询问用户是否指定。
3. 用户没有偏好时，在实时可用且满足硬性条件的模型中优先建议 Seedance 1.5 Pro，其次 Seedance 2.0；若两者均不可用，根据当前工具列表另行建议，不虚构模型。
4. 紧邻提交前展示已批准静帧版本、模型、时长、分辨率和预计消耗，再征得用户确认。费用无法核实时，必须取得用户对未知消耗的明确接受。
5. 提交 1 条试跑，不先批量消耗。
6. 保存真实任务 ID、平台、模型、耗时和消耗。
7. 只重跑失败条目，不自动换模型。

不要因为记得某个平台“应该支持”就猜参数；以当前工具声明为准。

## 3. 二级：用户指定平台 CLI

没有 Agent 内置能力时，询问用户：

> 你是否有常用或指定的视频生成平台？如果有，请提供它的官方 CLI 安装命令或文档链接。

获得 CLI 后：

1. 先阅读安装脚本或官方说明，再安装。
2. 运行 `<cli> --help` 和相关子命令 `--help`。
3. 只使用官方登录/授权流程，不索取 Cookie、token 或浏览器凭据。
4. 查询账户余额、会员要求、可用模型和首尾帧参数。
5. 如果 CLI 不支持尾帧，停止使用并进入下一级。
6. 根据 `duration-selection.md` 选择不短于目标的最小可用档位。
7. CLI 有模型可选时，先问用户是否指定。没有偏好时，只在平台当前实际可用且支持首尾帧的模型中优先建议 Seedance 1.5 Pro，其次 Seedance 2.0。
8. 提交前展示已批准静帧版本、模型、目标时长、实际提交时长、分辨率和积分/费用并再次确认；费用未知时单独说明并取得接受。
9. 保存任务 ID并轮询到真实终态；`submitted/querying` 不等于成功。

CLI 失败时呈现真实错误，不绕过 CLI 私自调用网页接口。

## 4. 三级：小云雀 CLI

用户没有指定平台时，推荐小云雀作为首选平台：

- 注册链接：<https://xiaoyunque.jianying.com/s/z_Wf-ql547E/>
- CLI 安装命令：

```bash
npx @pippit-dev/cli@latest install
```

- 模型候选优先级：平台当前实际可用且支持首尾帧时，优先 **Seedance 1.5 Pro**，其次 **Seedance 2.0**。

必须提醒用户：

1. 新用户注册通常有免费积分，具体额度以小云雀页面实时显示为准。
2. 通过 CLI 正式使用前，需要开通**最低档位的小云雀会员**；不要承诺永久免费。
3. 会员或积分属于付费事项，必须由用户本人完成。

用户完成注册和最低档会员开通后：

1. 执行官方安装命令。
2. 运行 CLI 帮助并完成其官方授权流程。
3. 查询实时模型与参数，不凭本文件猜命令。
4. 如果有多个满足首尾帧要求的模型，先询问用户是否指定。没有偏好时优先建议 Seedance 1.5 Pro；不可用或不满足要求时再建议 Seedance 2.0。
5. 展示不同候选的当前积分/费用、时长档位和分辨率差异，不假设名称相近就价格相同。
6. 目标参数：9:16、`duration_target` 对应的 4–15 秒档位、720p；以 CLI 当前声明为准。普通 B-roll 保留模型原始音轨和文件；只有完整讲解片额外生成无音频版。
7. 紧邻提交前确认获准静帧、模型和积分消耗；费用未知时取得用户明确接受。提交后保存任务 ID并轮询结果。

若用户不愿注册或开通会员，进入手动生成包。

## 5. 四级：手动生成包

用户没有任何平台 CLI，或不愿开通小云雀时，生成：

```text
<item>/manual-generation/
├── README.md
├── first-frame.png
├── last-frame.png
└── video-prompt.txt
```

先写英文 `video-prompt.txt` 与中文 `video-prompt-cn.txt`，再调用
`scripts/create_manual_package.py`。`README.md` 必须包含：

- 明确上传顺序：首帧先、尾帧后。
- 推荐参数：`duration_target` 对应的 4–15 秒时长、9:16、720p、关闭配音、锁定镜头。
- 英文和中文两版 prompt。
- 验收标准：空首帧、逐件组装、尾帧一致、无切镜/变焦/假字。
- 回传要求：生成后把原始 MP4 发回，由 Agent 做 QA。

仍可推荐用户在小云雀网页手动生成：

- 模型选择：页面实际可用且支持首尾帧时，优先 Seedance 1.5 Pro，其次 Seedance 2.0；上传前让用户查看页面显示的积分消耗。
- 注册链接：<https://xiaoyunque.jianying.com/s/z_Wf-ql547E/>。
- 新用户注册可能有免费积分，以平台实时显示为准；网页手动生成不等于 CLI 会员条件一定相同，必须让用户以页面提示为准。

不要只在对话里贴提示词；必须把两张帧和 prompt 复制到同一目录，形成可直接上传的完整包。

## 6. 五级：HyperFrames 最终兜底

只有同时满足以下条件才进入：

- 没有 Agent 内置视频能力。
- 没有可用平台 CLI。
- 用户不愿开通小云雀。
- 已提供手动生成包，但用户明确表示不会或无法在网站手动生成。

执行时使用已安装的 HyperFrames skill（如可用），并遵守其完整工作流：

1. 从确认静帧分离 3–4 个大组元素。
2. 抠成透明 PNG；优先保持原静帧元素与落点。
3. 以实测底色建立 1080×1920 画布。
4. 先实现静态完成态，再给各组添加 `steps(N)` 滑入与卡位。
5. 首帧保持纯色空场，结尾保持完成态。
6. `check`、快照目测、`render`、QA。

明确告诉用户其限制：HyperFrames 是确定性刚体动画，适合滑入、落位、堆叠；不能等价实现纸张形变、穿透、碎裂或有机运动。它是最终可交付兜底，不冒充 AI 视频模型效果。

## 7. 统一回收与 QA

无论视频来自 Agent、CLI、手动网站还是 HyperFrames，都执行同一回收流程：

1. 保存原始视频到 `<item>/video/run-v01/final.mp4`，该文件就是交付视频。
2. 普通 B-roll 不剥离音轨，也不为 QA 复制无音频文件。只有用户明确需要完整讲解片时，才额外创建 `final-noaudio.mp4`；原始文件始终保留。
3. 直接读取原始视频，生成逐秒 contact sheet、真实首帧、真实尾帧和尾帧对照图。
4. 记录平台、模型、任务 ID、实际消耗、分辨率、帧率、`duration_target`、`duration_submitted`、真实时长和 QA 结论。
5. 普通 B-roll 的原始交付文件不为统一帧率而自动转码。完整讲解片也保留模型原片；`assemble.py` 只在最终拼装过程中临时统一画布、帧率、像素格式和音频规格。
